# Словарь проекта «Стол и Кабинет»

Единственный источник правды для слов интерфейса. **Любой текст в UI берётся
отсюда.** Расходиться коду, спецификации и прототипу больше нельзя: меняем слово —
меняем сначала здесь, потом в коде. Технический жаргон в UI запрещён (§5.5).

Название продукта — **Стол и Кабинет**.

| Понятие | Слово в UI |

«Прописи» — базовый маршрут: **Не высушить → Сверить → Усилить**, затем аудит круга.

## Статусы разбора

(В интерфейсе автора слово «проход» не используется — справа в тетради
«Разборы». «Проход» осталось только во внутреннем коде как имя сущности Pass.
Слово «компас» тоже полностью убрано из интерфейса — только «наставник»; внутри
кода сущность по-прежнему зовётся Compass, на архитектуре это не сказывается.)

| Состояние | Слово в UI | Было |
|---|---|---|
| Промпт ещё не ушёл | **Черновик** | черновик |
| Депеша унесена наставнику, ждём ответа | **У наставника** | депеша отправлена |
| Разбор получен | **Разбор получен** | диагноз получен |
| Круг завершён | **Завершено** | — |

## Статусы изыскания

Изыскание — не проход по наставнику, а научная справка. Слово «наставник» тут
неуместно (§5.5): запрос уходит не мастеру, а возвращается справкой.

| Состояние | Слово в UI | Было (убрано) |
|---|---|---|
| Запрос ещё не ушёл | **Черновик** | черновик |
| Запрос отправлен, ждём справку | **Запрос отправлен** | ~~у наставника~~ |
| Справка получена | **Справка получена** | ~~разбор получен~~ |

Кнопка вставки ответа в изыскании — **Вставить ответ** (без «наставника»).

## Два процесса голоса (источник правды — docs/ДВА-ПРОЦЕССА.md)

Единица анализа делит всё надвое: **один текст** или **автор** (голос поверх
текстов).

- **Разбор роста** (в тетради) — нарративная траектория ОДНОГО текста через
  версии: что окрепло, над чем поработать, следующий шаг. Открывается при ≥2
  сверках.
- **Голос автора** (Кабинет → Голос) — кросс-текстовый портрет: что в голосе
  уже звучит уверенно, а что ещё колеблется. Открывается, когда **≥3 разных
  текста прошли полный цикл** (Не высушить → ≥2 Сверить → Усилить → правка).

Старые «Сверка голоса» (лёгкое зеркало 1.0) и «Как растёт ваш голос» (снимок по
осям одного наставника) убраны по решению автора — «одна сущность голоса». Они и
были источником путаницы «текст ↔ автор»: срабатывали от одной сверки. Прежние
сверки автора остаются свёрнутой историей на странице «Голос». Полный **Аудит
корпуса** (авто-ведение ядра, замеров, история) приберегается под версию 2.0.
