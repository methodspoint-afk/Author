# Словарь проекта «Стол и Кабинет»

Единственный источник правды для слов интерфейса. **Любой текст в UI берётся
отсюда.** Расходиться коду, спецификации и прототипу больше нельзя: меняем слово —
меняем сначала здесь, потом в коде. Технический жаргон в UI запрещён (§5.5).

Название продукта — **Стол и Кабинет**.

## Территории

| Понятие | Слово в UI |
|---|---|
| Главная, место Редактора | **Стол** |
| Раздел Секретаря | **Кабинет** |

| Состояние текста в момент времени | **Версия** |

## Статусы изыскания

Изыскание — не проход по наставнику, а научная справка. Слово «наставник» тут
неуместно (§5.5): запрос уходит не мастеру, а возвращается справкой.

| Состояние | Слово в UI | Было (убрано) |
|---|---|---|
| Запрос ещё не ушёл | **Черновик** | черновик |
| Запрос отправлен, ждём справку | **Запрос отправлен** | ~~у наставника~~ |
| Справка получена | **Справка получена** | ~~разбор получен~~ |

Кнопка вставки ответа в изыскании — **Вставить ответ** (без «наставника»).

кнопке «Собираю сводку…» / «Вношу…» / «Обновляю…», после — короткая
галочка-подтверждение «✓ Сводка готова — она ниже, в проходах.» / «✓ Внесено в
картотеку.» / «✓ Обновлено в картотеке.» (гаснет сама через несколько секунд).

## Сверка голоса и аудит корпуса

В версии 1.0 «Сверка голоса» — лёгкое зеркало: секретарь смотрит на пары
«было ↔ стало» и называет 2–3 повторяющиеся черты правок (что уверенно, что
качается). Файлов не пишет, «ядро голоса» и замеры наставников не ведёт —
выводы делает автор. Полный **Аудит корпуса** (авто-ведение ядра, замеров,
история) приберегается под версию 2.0.
